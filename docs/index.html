        Read. Verify.Decide. Log.

        The phone sends one photo to one Python server. The server runs four steps and streams each one back the moment it finishes, so you watch Plainly read, search and decide instead of staring at a spinner.

        Tiger Data

        Every check writes one anonymous row. Tiger turns those rows into the This week in New York panel on the home screen.

        • Hypertable split into one-day chunks
        • Real-time continuous aggregate keeps daily counts by category and verdict, so a new check shows up immediately
        • Compression policy after seven days
        • Stored: category, verdict, document type, and for scams only, the link's domain
        CREATE TABLE checks (
  time TIMESTAMPTZ NOT NULL DEFAULT now(),
  category TEXT, verdict TEXT, doc_type TEXT,
  domain TEXT, city TEXT, is_seed BOOLEAN
);
SELECT create_hypertable('checks',
  by_range('time', INTERVAL '1 day'));

CREATE MATERIALIZED VIEW checks_daily
  WITH (timescaledb.continuous,
        timescaledb.materialized_only = false) AS
SELECT time_bucket('1 day', time) AS day,
       category, verdict, count(*) AS n
FROM checks GROUP BY day, category, verdict;

SELECT add_compression_policy('checks', INTERVAL '7 days');

        Watching it work

        Sentry records one trace per check, named plainly.analyze, with a span for each step and each outside call. Gemini calls are traced automatically, with the prompts left out for privacy.

        plainly.analyzegen_ai.invoke_agent

        │ └─ gemini gemini-3.8-flashgen_ai.request
        ├─ verify on the webgen_ai.execute_tool
        │ ├─ nimble search: officialhttp.client
        │ ├─ nimble search: scam_checkhttp.client
        │ └─ nimble search: ruleshttp.client
        └─ decide verdictgen_ai.invoke_agent
        └─ gemini gemini-3.8-flashgen_ai.request

        How it stays honest

        • Cited links must be pages Nimble actually fetched. Any other URL in Gemini's answer is dropped.
        • Phone numbers in a script must be printed on the document or found on an official source. Scams never get one.
        • Confidence is shown next to every verdict.
        • Every plan says to contact the organization through a site or number you look up yourself.
        • Answers are checked against a fixed schema before they reach the phone.

        Privacy

        • Photos go to Gemini for analysis and are never stored.
        • The trends table keeps category, verdict and document type. For scams it also keeps the link's domain, so the panel can list the most-flagged links.
        • No names, account numbers or images are saved anywhere.
        • Sentry traces timings and errors, not prompts.
